 # Sistema de Evaluación de Madurez Tecnológica para PYMES

Sistema híbrido (online/offline) que evalúa el nivel de madurez tecnológica
de pequeñas y medianas empresas del sector desarrollo de software,
utilizando los marcos de referencia CMMI, COBIT, ISO 25010 e ITIL.

## Tecnologías

- **.NET 8** (Windows Forms)
- **C# 12**
- **SQLite** para persistencia local
- **PdfPig** para lectura de PDFs
- **API de Anthropic Claude Sonnet 4.6** para análisis inteligente

## Arquitectura

Arquitectura por capas:

- `Presentacion/`: formularios Windows Forms
- `Logica/`: orquestadores y gestores de negocio
- `Inteligencia/`: cliente IA, prompts, detector de conexión, motor de reglas (offline)
- `Datos/`: base de datos SQLite y repositorios
- `Modelos/`: entidades del dominio

## Modos de operación

- **Online**: utiliza Claude Sonnet 4.6 para análisis profundo y conversación
- **Offline**: motor de reglas + cuestionario estructurado (en desarrollo)

El sistema detecta automáticamente la disponibilidad de internet
y selecciona el modo apropiado. El usuario también puede forzar
el modo offline manualmente.

## Configuración

1. Obtener una API Key de Anthropic en console.anthropic.com
2. Crear el archivo `appconfi.json` en la raíz del proyecto con:

```json
{
  "ApiKey": "sk-ant-api03-...",
  "Modelo": "claude-sonnet-4-6",
  "MaxTokens": 4000
}
```

3. Compilar y ejecutar con Visual Studio 2022 o superior.

# Resultados de Pruebas — Sistema de Evaluación de Madurez Tecnológica

## Validación de discriminación de niveles CMMI

**Fecha de pruebas:** 24 de mayo de 2026
**Versión del sistema:** Final de Semana 3 (diagnóstico estructurado)
**Modelo de IA:** Claude Sonnet 4.6 (claude-sonnet-4-6)

### Metodología

Se generaron 3 informes empresariales ficticios diseñados para representar
3 niveles distintos del modelo CMMI:

- **Nivel 1 (Inicial)** — CodeMinka, C.A.: 8 empleados, procesos caóticos, sin pruebas, sin CI/CD
- **Nivel 3 (Definido)** — Codex Digital, C.A.: 42 empleados, Scrum formal, ISO 27001
- **Nivel 5 (Optimizado)** — Quantum Software Group: 287 empleados, ML predictivo, A/B testing automatizado

Cada informe fue analizado por el sistema, que devolvió un diagnóstico
estructurado con nivel CMMI estimado.

### Resultados

| Empresa                       | Esperado | Obtenido | Coincidencia |
|-------------------------------|----------|----------|--------------|
| CodeMinka, C.A.               | 1        | 1        | ✓ Exacto     |
| Codex Digital, C.A.           | 3        | 3        | ✓ Exacto     |
| Quantum Software Group        | 5        | 5        | ✓ Exacto     |

**Tasa de acierto: 3/3 (100%)**

### Conclusión

El sistema discrimina correctamente entre niveles CMMI con distancia
significativa (1, 3 y 5). Los diagnósticos coinciden exactamente con
el nivel esperado en todos los casos probados.
